# The Bulk Hunter Slab Vault demo

Open-in-browser personal sandbox. Each visitor has independent fictional sample inventory and demo admin controls; no purchases, customer data, real prizes, or shared production stock. No sign-in or installation is required.

The sandbox runs the same inventory API and rules in browser-local SQLite (sql.js/WASM), saved in this browser. Use Reset my demo to start over. Clearing browser storage resets your samples.

The complete shared-server source is maintained separately.
